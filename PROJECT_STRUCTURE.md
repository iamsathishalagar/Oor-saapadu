# Project Structure

This document outlines the folder structure, files, and purpose of all major files in the 'Oor-saapadu' repository.

## Folder Structure

```
Oor-saapadu/
├── src/
│   ├── main/
│   ├── test/
│   └── resources/
├── docs/
├── scripts/
└── README.md
```

## Explanation of Major Files

### `src/`
Contains all the source code for the project, split into main and test directories.

- **`main/`**: This directory contains the primary application code.
- **`test/`**: Contains all unit tests and integration tests for the application.
- **`resources/`**: Holds configuration files or other resources needed by the application.

### `docs/`
Documentation related to the project. Includes API documentation and setup guides.

### `scripts/`
Any scripts related to project automation, such as build scripts or deployment scripts.

### `README.md`
The main entry point for project documentation explaining how to set up and run the project.
