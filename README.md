# Oor Saapadu

Oor Saapadu is a hyperlocal food ordering website designed to connect local hotels with nearby customers.

## Features
- Hotel listing system
- Search functionality
- Firebase database integration
- Admin management
- Responsive UI design

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase
